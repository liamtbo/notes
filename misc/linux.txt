installing packages
    sudo apt install <package>
        “System-approved version of packages”
        Installs the package version that Debian (and ROS) tested and built against.
        It’s usually older but guaranteed to work with your OS and ROS release.
        installs in /usr/lib
        
    pip install <package>
        “Latest version from the internet”
        Installs directly from PyPI (Python Package Index) — often newer, but it can break system tools or ROS because it may override or conflict with the versions Debian packaged.
        Context	                                Install path
        System Python (pip install ...)	        /usr/local/lib/python3.X/dist-packages/
        User install (pip install --user ...)	~/.local/lib/python3.X/site-packages/
        Virtualenv or Conda	                    ~/env_name/lib/python3.X/site-packages/


problem
    folder with subfolders full of images that I want to put all into one folder
solution
    find <parent path> -mindepth 2 -type f -exec mv -t <cuml folder path> {} +
        find <parent path>
            starting dir that find will search for files
        -mindepth 2
            ensures find only considers files that are insdie subdirs
        -type f
            tells find to only look for files
        -exec mv -t <cuml folder path> {} +
            -exec mv
                executes mv
            -t <cuml folder path>
                target dir specification
            {}
                placeholder for each file found by find
            +
                tells find to pass multiple files paths at once to mv command (faster then one at a time)

problem
    how many file are in a folder
solution
    find <folder path> -type f | wc -l
        find <folder path>
            searches in folder specified
        -type f
            only files, not dirs
        | wc -l
            pipes output (list of files) to wc -l, which counts the number of lines, each representing a file
